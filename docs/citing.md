# Citing pylfit

> Placeholder: a paper describing pylfit 1.0 and a DOI for each
> release are still to come. This page will give them once they exist.

If you use pylfit in published work, cite the software for now. Once
releases have a DOI, cite the DOI of the release you used.
<!-- DOI placeholder: per-release DOI (for example, Zenodo), to come. -->

```text
Ribeiro, T. pylfit (Version <the version you used>) [Computer
software].
https://github.com/Tony-sama/pylfit
```

The repository's `CITATION.cff` holds the same information in a
machine-readable form; GitHub shows it as "Cite this repository".

Cite the papers behind the algorithms you use as well:

- The LFIT framework: K. Inoue, T. Ribeiro, C. Sakama. Learning from
  interpretation transition. *Machine Learning* 94(1):51-79, 2014.
  <https://doi.org/10.1007/s10994-013-5353-8>
- `GULA`: T. Ribeiro, M. Folschette, M. Magnin, O. Roux, K. Inoue.
  Learning dynamics with synchronous, asynchronous and general
  semantics. *Inductive Logic Programming (ILP 2018)*, LNCS 11105,
  pp. 118-140, 2018.
  <https://doi.org/10.1007/978-3-319-99960-9_8>;
  and T. Ribeiro, M. Folschette, M. Magnin, K. Inoue. Learning any
  memory-less discrete semantics for dynamical systems represented by
  logic programs. *Machine Learning* 111(10):3593-3670, 2022.
  <https://doi.org/10.1007/s10994-021-06105-4>
- `PRIDE`: T. Ribeiro, M. Folschette, M. Magnin, K. Inoue. Polynomial
  algorithm for learning from interpretation transition. *1st
  International Joint Conference on Learning and Reasoning (IJCLR
  2021)*, late-breaking abstract, 2021.
  [hal-03347026](https://hal.science/hal-03347026)
- Learning from unknown values: T. Ribeiro, M. Folschette, M. Magnin,
  K. Okazaki, K.-Y. Lo, A. Roquilly, J. Poschmann, K. Inoue. Learning
  from interpretation transitions with unknowns. *4th International
  Joint Conference on Learning and Reasoning (IJCLR 2024)*, pp.
  66-85, 2024. <https://doi.org/10.1007/978-3-032-09087-4_5>;
  [hal-04634356](https://hal.science/hal-04634356)

The people who developed LFIT are credited on the [Credits](credits.md)
page.

For work that used pylfit 0.x, cite the release you used, and the
papers that version's documentation lists; see the `v0.5.1` tag of the
repository.

# Tutorials

Each tutorial takes one problem from the data to rules that explain
it, step by step. Start with [Getting started](../getting-started.md),
then pick the tutorial closest to your data:

- [Predict heart disease from clinical
  data](../auto_examples/tutorial_heart_disease.rst): a table of
  clinical measurements, one row per patient, and a diagnosis to
  predict.
- [Learn a gene regulatory network](gene-network.md): time series of
  gene expression, and the rules by which the genes regulate each
  other.

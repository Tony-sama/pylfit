# Security

To report a security problem in pylfit, write to
tonyribeiro.contact@gmail.com rather than opening a public issue, with
the pylfit version and a description or code that shows the problem.
You will get a reply before anything about it is made public.

Fixes go into the latest release only. One part of the design is
security-relevant: saved models are JSON, and loading one never runs
code from the file.
